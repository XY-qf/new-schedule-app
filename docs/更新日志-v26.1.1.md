## 修复的问题

### 1. 重要日不能删除、点条目跳到新建

- 点条目现在是**进入编辑**，名称、日期、每年重复都能改
- 编辑界面左下角新增「删除」，二次确认后删除
- 每年重复的重要日，2 月 29 日在平年会落到 2 月 28

### 2. 提醒最多只能提前 30 分钟

提醒选项扩展为：

| 选项 | 说明 |
| --- | --- |
| 不提醒 | — |
| 准时 | 日程开始时 |
| 提前 5 / 10 / 15 / 30 分钟 | — |
| 提前 1 小时 / 2 小时 | 新增 |
| **提前 1 天（可定时刻）** | 新增，可指定前一天几点提醒，默认 09:00 |

### 3. 新建待办没有提醒

勾选「安排时间」后，下方出现「待办提醒」下拉，选项与日程一致（不提醒 / 准时 / 提前 5–60 分钟）。

> 纯任务（不安排时间的）没有时刻，无法提醒，所以不显示这一项。

### 4. 重要日显示「已过 N 天」

每年重复的重要日（生日、纪念日）现在**只往前看**：
- 今年的过了，自动算到明年的天数
- 排版上也不再标记为「已过期」（灰色）

排序同步修正：过去的日子不再沉到列表底部。

### 5. 重复规则要再选一次时间

- 选「每周」时，**自动勾上日程本身就是星期几**
- 选「每月」时，**自动填入日程本身是几号**

不用再手动重复选一遍。

### 6. 提醒板块的位置

新建/编辑日程的表单顺序调整为：

```
标题 → 分类 → 时间 → 加入待办 → 备注 → 重复 → 提醒 → 按钮
```

提醒移到了最后。

### 7. 新建日程没有备注

新增「备注」输入框，保存后会存下来，再次编辑时自动带出。

### 8. 需要按分类批量删除日程

设置 → 分类管理，每条分类多了一个「清空日程」按钮：

- 二次确认
- **只删日程，分类本身和其他分类不受影响**
- 删完提示「已删除 N 条日程」
