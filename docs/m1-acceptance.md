# M1 人工验收清单

自动化测试（`pnpm test` / `pnpm test:ui` / `pnpm e2e`）覆盖了逻辑与主流程，但**窗口手感、字体渲染、动画**这类东西只有人眼能判断。下面每一项都是可以 30 秒内验完的。

## 准备

```powershell
cd "$env:USERPROFILE\Desktop\待办\AI待办软件"
pnpm install
pnpm dev
```

> 若报 `Cannot read properties of undefined (reading 'whenReady')`，先执行 `Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue` 再启动。

## 一、窗口

- [ ] 打开后窗口约 `1000×700`，居中在屏幕
- [ ] 没有系统标题栏；顶部一整条可以拖动窗口
- [ ] 右上角三个按钮：最小化、最大化/还原、关闭，鼠标悬停有反馈
- [ ] 点「最大化」铺满工作区且不遮任务栏；再点一次回到原尺寸
- [ ] 点「关闭」窗口消失但**进程还在**（M1 还没有托盘，用任务管理器能看到 `electron.exe`）
  - 这是刻意的：托盘在 M4 落地，届时关闭才真正「缩到托盘」

## 二、周视图

- [ ] 七列，**周一是第一列**
- [ ] 今天那一列的表头和日期是蓝色加粗，列底色略有高亮
- [ ] 打开时垂直位置停在 **07:00 附近**，不是 00:00
- [ ] 时间轴左侧刻度 00:00–23:00 对齐网格线
- [ ] 按小时的水平网格线可见但不刺眼
- [ ] 右侧**没有**灰色滚动条
- [ ] 当天有日程时，能看到一条**红色细线**标记当前时间

## 三、翻周与编辑删除

- [ ] 顶部有「‹ 10月19日 – 10月25日 ›」和「今天」按钮
- [ ] 点「‹」回到上一周，列头日期跟着变；点「今天」跳回本周
- [ ] 点任意日程色块，弹出编辑表单，标题已填好
- [ ] 改完标题保存，色块上的文字立刻更新
- [ ] 编辑表单里有「删除」按钮，点击二次确认后消失

## 四、新建日程

点右下角蓝色「＋」：

- [ ] 弹出表单，标题为空时「保存」是灰的、点不动
- [ ] 分类按钮有颜色圆点（课程=蓝、课外活动=橙、个人生活=绿）
- [ ] 时间形态有四档：全天 / 时间段 / 只有开始 / 只有结束
  - 选「全天」→ 只剩开始时间输入框
  - 选「只有结束」→ 只剩结束时间输入框
- [ ] 填「时间段」保存后，周视图出现一个**色块**，块里显示标题和 `08:00–09:35`
- [ ] 填「只有结束」保存后，出现一条**虚线横线**（不是色块）
- [ ] 填「全天」保存后，出现在顶部**全天行**里
- [ ] 标题写 60 个字，色块里显示成省略号，不撑破列宽

## 五、数据

- [ ] 关掉应用（任务管理器结束 `electron.exe`），重新 `pnpm dev`，刚才建的日程**都还在**
- [ ] 数据文件位置：`%APPDATA%\ai-todo-app\data\app.db`

## 六、视图切换

- [ ] 点顶部「待办」，窗口**自动变窄**到约 `400×822`
- [ ] 再点「日历」，窗口恢复约 `1000×700`
- [ ] 切换时窗口中心点不跳变

把现象、复现步骤、期望行为写下来即可，例如：

> 周三的日程块高度看起来比 08:00–09:35 高，应该是 1.58 小时 × 48px ≈ 76px
