# 人工验收清单（M1 + M2 + M3）

自动化测试覆盖了逻辑与主流程（`pnpm test` 80 条 / `pnpm test:ui` 26 条 / `pnpm e2e` 4 条），但**窗口手感、字体渲染、动画、真实缩放下的观感**只有人眼能判断。

下面每一条都是 1 分钟内能验完的。**第一节到第六节是 M1**，**第七节起是 M2**。

## 0. 准备

```powershell
cd "$env:USERPROFILE\Desktop\待办\AI待办软件"
pnpm install
pnpm dev
```

> 若报 `Cannot read properties of undefined (reading 'whenReady')`，先执行
> `Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue` 再启动。

数据文件位置：`%APPDATA%\AI待办软件\data\app.db`

---

## 一、窗口

- [ ] 打开后窗口约 `1000×700`，居中
- [ ] 没有系统标题栏；**顶部整条（标题栏 + 标签栏空白处）都能拖动窗口**
- [ ] 右上角三个按钮：最小化 / 最大化 / 关闭，鼠标悬停有反馈
- [ ] 点「最大化」→ 铺满工作区且**不遮任务栏**
- [ ] 最大化后按钮变成**两个重叠方框的「还原」图标**，悬停提示也变成「还原」
- [ ] 再点一次「还原」→ 回到原来的尺寸和位置
- [ ] 最大化状态下切到「待办」→ 窗口**变回窄形态**（约 400×822），不是全屏
- [ ] 切回「日历」→ 恢复成宽窗口
- [ ] 手动把窗口拖到最小，七列不会挤烂（有最小尺寸兜底）
- [ ] 切换视图时窗口是**平滑变化**，不是瞬间跳变
- [ ] 点「关闭」→ 应用**真正退出**（任务管理器里 `electron.exe` 消失）

## 二、周视图

- [ ] 七列，**周一是第一列**
- [ ] 顶部显示 `10月19日 – 10月25日` 这样的周范围
- [ ] 点「‹」回到上一周，列头日期整体前移 7 天
- [ ] 点「›」到下一周，列头日期整体后移 7 天
- [ ] 点「今天」跳回本周，今天列蓝色高亮
- [ ] 打开时垂直位置停在 **07:00 附近**，不是 00:00
- [ ] 时间轴刻度 00:00–23:00 与网格线对齐；网格线可见但不刺眼
- [ ] 右侧**没有**灰色滚动条
- [ ] 今天那一列有一条**红色细线**标记当前时间
- [ ] **等 2 分钟，红线会跟着往下走**（不是停在打开那一刻）
- [ ] 跨午夜的日程（如 23:00–次日 02:00）在两天都显示，各显示自己那半段
- [ ] 跨多天的全天日程（如 3 天旅行）在覆盖的每一天都出现
- [ ] 同一天超过 2 条全天事项时，第 3 条起折叠成「还有 N 条」

## 三、新建日程

点右下角蓝色「＋」：

- [ ] 标题为空时「保存」是灰的、点不动
- [ ] 分类按钮带颜色圆点（课程=蓝、课外活动=橙、个人生活=绿）
- [ ] 时间形态四档：全天 / 时间段 / 只有开始 / 只有结束
- [ ] 选「全天」→ 输入框变成**两个日期框**（开始日期 / 结束日期），没有时刻
- [ ] 选「时间段」→ 开始时间 + 结束时间两个框
- [ ] 选「只有结束」→ 只剩结束时间
- [ ] 时间段填反（结束早于开始）→ 出现**红字提示** + 两个时间框描红 + 保存按钮置灰，不是英文数据库错误
- [ ] 保存「时间段」→ 周视图出现**色块**，块内显示标题和 `08:00–09:35`
- [ ] 保存「只有结束」→ 出现一条**虚线横线**（不是色块）
- [ ] 保存「全天」→ 出现在顶部**全天行**
- [ ] 标题写 60 个字 → 色块里显示省略号，不撑破列宽
- [ ] 表单里有「加入待办」开关：勾上后保存，这条日程会出现在待办列表里；不勾则不进
- [ ] 保存一条**下周**的日程 → 视图自动跳到那一周，并提示「已保存到那周」
- [ ] 保存成功后底部出现「已保存」提示，约 2 秒后消失

## 四、编辑与删除

- [ ] 点任意色块 → 弹出编辑表单，标题、分类、时间都已填好
- [ ] 点横线（只有结束时间的日程）同样能打开编辑
- [ ] 点全天行的胶囊同样能打开编辑
- [ ] 改标题保存 → 色块上的文字立刻更新
- [ ] 编辑表单左下角有「删除」，点击弹二次确认
- [ ] 确认删除 → 该日程从周视图消失，并提示「已删除」

## 五、数据

- [ ] 建 3 条日程 → 关掉应用 → 重新打开，3 条都在
- [ ] 用任务管理器**强杀** `electron.exe` → 重新打开，数据仍然在（不会损坏）
- [ ] 连续双击启动两次 → **只有一个窗口**（第二个实例会把已有窗口顶到前面）
- [ ] 数据文件确实在 `%APPDATA%\AI待办软件\data\app.db`

## 六、视图切换与细节

- [ ] 点顶部「待办」→ 窗口变窄；再点「日历」→ 变宽
- [ ] 切换时窗口中心点不跳变
- [ ] 整体配色是暖白（米白面板 + 深灰文字），不是刺眼的纯白
- [ ] 拖窗口时不会误触成拖日程（M1 还没做日程拖拽，这一条是确认「没有多余行为」）

## 七、日历三种粒度（M2）

- [ ] 顶部有「日 / 周 / 月」分段控件，当前粒度高亮
- [ ] 切到「日」→ 只显示一天，标题是「10月19日 周一」
- [ ] 点「‹」「›」按天前后移动；点「今天」回到今天
- [ ] 切到「月」→ 6×7 网格，**周一是第一列**
- [ ] 月的标题显示「2026年 10月」，上下月日期是浅底
- [ ] 今天在月视图里是蓝色圆徽标
- [ ] 同一天超过 2 条日程时折叠成「还有 N 条」
- [ ] 点月视图里任意一天（包括上下月的日期）→ 跳到**那一天**的日视图
- [ ] 切到「周」→ 回到七列，且仍是刚才那一周

## 八、重复规则（M2）

- [ ] 新建日程时，「重复」一行默认是「不重复」
- [ ] 选「每周」→ 出现星期一~日的多选，可以多选
- [ ] 选「每月」→ 出现「每月几号」输入，超出 1–31 会被夹回来
- [ ] 能设「重复结束日期」，留空表示一直重复
- [ ] 底部摘要实时更新，例如「每周 二、四，直到 2027-01-15」
- [ ] 建一条「每周二、四」的课 → 本周二和周四各出现一次
- [ ] 翻到下周 → 仍然是周二、周四各一次

## 九、只改这一次 / 改整个序列（M2）

- [ ] 点重复日程的某一次 → 表单里出现「改动范围：仅这一次 / 整个序列」，默认「仅这一次」
- [ ] 选「仅这一次」改标题 → **只有那一天变**，同系列其它天不变
- [ ] 翻到下一周 → 标题回到原来的
- [ ] 选「整个序列」改标题 → 所有实例都变
- [ ] 删除时选「仅这一次」→ 确认框写的是「只删除这一次」，删完其它天还在

## 十、按节次填时间（M2）

- [ ] 选「时间段」后，下方出现**「精确时间 / 按节次」二选一**，默认「精确时间」
- [ ] 「精确时间」下只有开始/结束时间输入，**看不到节次下拉**
- [ ] 点「按节次」→ 时间输入消失，换成「日期 + 第 N 节 – 第 M 节」
- [ ] 选第 1–2 节时，右侧实时显示 `08:00–09:35`
- [ ] 按节次保存后，周视图色块时间就是 08:00–09:35
- [ ] 按节次但没选日期 → 提示「请选择日期」
- [ ] 结束节次早于开始节次 → 提示「结束节次不能早于开始节次」
- [ ] 用「精确时间」建的日程，再打开编辑时停在「精确时间」；用「按节次」建的停在「按节次」

## 十一、待办视图（M3）

- [ ] 右下「＋」→ 新建待办表单
- [ ] 不勾「安排时间」→ 保存后是一条**纯任务**（没有时刻）
- [ ] 勾上「安排时间」→ 出现日期 + 起止时刻，保存后是一条**带时间、自动加入待办**的日程
- [ ] 勾了时间但结束早于开始 → 红字提示「结束时间不能早于开始时间」

- [ ] 点顶部「待办」→ 窗口变窄，列表出现
- [ ] 顶部有「全部 / 课程 / 课外活动 / 个人生活」胶囊，选中态高亮
- [ ] 每行是：圆形勾选框 + 分类色点 + 标题 + 第二行时间
- [ ] 时间显示按类型变化：`14:00–15:30` / `截止 23:59` / `全天` / 纯任务显示备注
- [ ] 只有勾了「加入待办」的日程会出现在这里，普通日程不进
- [ ] 排序：按时间先后，**纯任务排在最后**
- [ ] 点勾选框 → 该行淡出并移入「已完成 N」折叠区
- [ ] 点「已完成 N」能展开回看，再点收起
- [ ] **点日程行** → 打开日程编辑
- [ ] **点任务行** → 打开任务编辑，标题/分类/备注都已填好，改完保存生效
- [ ] 勾选框与行点击互不干扰（点勾选框不会同时打开编辑）
- [ ] 底部「回到日历」→ 窗口变宽并回到日历

## 十二、重要日倒计时（M3）

- [ ] 待办视图里有一个「重要日倒计时 · N 条 · 最近一条 D-n」的标题行
- [ ] 默认是**折叠**的，只显示这一行
- [ ] 折叠状态下，标题行右侧的「＋」仍然能直接新建（不用先展开）
- [ ] 点标题行展开/收起，折叠状态在重启后还记得
- [ ] 新建时填名称 + 日期 → 保存后出现在区块里
- [ ] 未来日期显示 `D-n`，今天显示 `今天`，过去显示 `已过 n 天`
- [ ] 多个重要日：未来的排在前面按日期升序，过去的排在后面

## 十四、提醒、托盘与迷你弹窗（M4）

- [ ] 新建日程时「提醒」一行能选：不提醒 / 准时 / 提前 5 / 10 / 30 分钟
- [ ] 建一条 1 分钟后开始、选「准时」的日程 → 到点弹**系统通知**
- [ ] 同时屏幕**右下角**出现一个无边框迷你窗，显示标题与时刻
- [ ] 迷你窗不抢焦点（弹出来时你还能在别的窗口打字）
- [ ] 点迷你窗正文 → 主窗口被唤起
- [ ] 点迷你窗的 × → 迷你窗消失
- [ ] 点主窗口关闭按钮 → **窗口消失但进程还在**（任务管理器里 electron.exe 仍存在）
- [ ] 点击托盘图标 → 窗口回来
- [ ] 托盘右键 → 打开主窗口 / 新建日程 / 退出
- [ ] 托盘菜单点「退出」→ 先弹确认「退出后将收不到提醒」，取消则不退
- [ ] **主窗口隐藏到托盘时**，到点仍然弹迷你窗（这条最能体现 M4 的价值）

## 十五、设置、主题与备份（M5）

- [ ] 点标题栏中间的 ⚙ → 弹出设置弹层（约 700×600）
- [ ] 「外观」三选一：浅色 / 深色 / 跟随系统，切换**立即生效**
- [ ] 切到深色后关掉应用再开，仍是深色
- [ ] 「作息时间表」能改每节起止时间、加一节、删一节、一键恢复默认 12 节
- [ ] 「分类管理」能改名、点色块换颜色、切换提醒开关；内置分类的删除按钮是灰的
- [ ] 「数据」能导出备份（选目录 → 生成 `ai-todo-backup-日期-时间.db`）
- [ ] 「数据」能打开数据文件夹
- [ ] 「系统」能切换开机自启，重启电脑后应用自动启动
- [ ] 关于信息显示版本号与数据目录
