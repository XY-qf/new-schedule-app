# M1 人工验收清单

自动化测试覆盖了逻辑与主流程（`pnpm test` 80 条 / `pnpm test:ui` 26 条 / `pnpm e2e` 4 条），但**窗口手感、字体渲染、动画、真实缩放下的观感**只有人眼能判断。

下面每一条都是 1 分钟内能验完的。全部通过，M1 就算真正收尾。

## 0. 准备

```powershell
cd "$env:USERPROFILE\Desktop\待办\AI待办软件"
pnpm install
pnpm dev
```

> 若报 `Cannot read properties of undefined (reading 'whenReady')`，先执行
> `Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue` 再启动。

数据文件位置：`%APPDATA%\AI待办软件\data\app.db`

## 一、窗口

- [ ] 打开后窗口约 `1000×700`，居中
- [ ] 没有系统标题栏；**顶部整条（标题栏 + 标签栏空白处）都能拖动窗口**
- [ ] 右上角三个按钮：最小化 / 最大化 / 关闭，鼠标悬停有反馈
- [ ] 点「最大化」→ 铺满工作区且**不遮任务栏**
- [ ] 最大化后按钮**变成「还原」**（图标与悬停提示都变）
- [ ] 再点一次「还原」→ 回到原来的尺寸和位置
- [ ] 最大化状态下切到「待办」→ 窗口**变回窄形态**（约 400×822），不是全屏
- [ ] 切回「日历」→ 恢复成宽窗口
- [ ] 手动把窗口拖到最小，七列不会挤烂（有最小尺寸兜底）
- [ ] 切换视图时窗口是**平滑变化**，不是瞬间跳变
- [ ] 点「关闭」→ 应用**真正退出**（任务管理器里 `electron.exe` 消失）

## 二、周视图

- [ ] 七列，**周一是第一列**
- [ ] 顶部显示 `10月19日 – 10月25日` 这样的周范围
- [ ] 点「‹」回到上一周，列头日期整体前移 7 天
- [ ] 点「›」到下一周，列头日期整体后移 7 天
- [ ] 点「今天」跳回本周，今天列蓝色高亮
- [ ] 打开时垂直位置停在 **07:00 附近**，不是 00:00
- [ ] 时间轴刻度 00:00–23:00 与网格线对齐；网格线可见但不刺眼
- [ ] 右侧**没有**灰色滚动条
- [ ] 今天那一列有一条**红色细线**标记当前时间
- [ ] **等 2 分钟，红线会跟着往下走**（不是停在打开那一刻）
- [ ] 跨午夜的日程（如 23:00–次日 02:00）在两天都显示，各显示自己那半段
- [ ] 跨多天的全天日程（如 3 天旅行）在覆盖的每一天都出现
- [ ] 同一天超过 2 条全天事项时，第 3 条起折叠成「还有 N 条」

## 三、新建日程

点右下角蓝色「＋」：

- [ ] 标题为空时「保存」是灰的、点不动
- [ ] 分类按钮带颜色圆点（课程=蓝、课外活动=橙、个人生活=绿）
- [ ] 时间形态四档：全天 / 时间段 / 只有开始 / 只有结束
- [ ] 选「全天」→ 输入框变成**两个日期框**（开始日期 / 结束日期），没有时刻
- [ ] 选「时间段」→ 开始时间 + 结束时间两个框
- [ ] 选「只有结束」→ 只剩结束时间
- [ ] 时间段填反（结束早于开始）→ 出现**中文**提示，不是英文数据库错误
- [ ] 保存「时间段」→ 周视图出现**色块**，块内显示标题和 `08:00–09:35`
- [ ] 保存「只有结束」→ 出现一条**虚线横线**（不是色块）
- [ ] 保存「全天」→ 出现在顶部**全天行**
- [ ] 标题写 60 个字 → 色块里显示省略号，不撑破列宽
- [ ] 保存一条**下周**的日程 → 视图自动跳到那一周，并提示「已保存到那周」
- [ ] 保存成功后底部出现「已保存」提示，约 2 秒后消失

## 四、编辑与删除

- [ ] 点任意色块 → 弹出编辑表单，标题、分类、时间都已填好
- [ ] 点横线（只有结束时间的日程）同样能打开编辑
- [ ] 点全天行的胶囊同样能打开编辑
- [ ] 改标题保存 → 色块上的文字立刻更新
- [ ] 编辑表单左下角有「删除」，点击弹二次确认
- [ ] 确认删除 → 该日程从周视图消失，并提示「已删除」

## 五、数据

- [ ] 建 3 条日程 → 关掉应用 → 重新打开，3 条都在
- [ ] 用任务管理器**强杀** `electron.exe` → 重新打开，数据仍然在（不会损坏）
- [ ] 连续双击启动两次 → **只有一个窗口**（第二个实例会把已有窗口顶到前面）
- [ ] 数据文件确实在 `%APPDATA%\AI待办软件\data\app.db`

## 六、视图切换与细节

- [ ] 点顶部「待办」→ 窗口变窄；再点「日历」→ 变宽
- [ ] 切换时窗口中心点不跳变
- [ ] 整体配色是暖白（米白面板 + 深灰文字），不是刺眼的纯白
- [ ] 拖窗口时不会误触成拖日程（M1 还没做日程拖拽，这一条是确认「没有多余行为」）
