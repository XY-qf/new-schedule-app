# 人工自查表 · v26.1.1

> 只列**本次更新涉及**的项目，每条 1 分钟内可验完。打勾即通过。

## 一、重要日（反馈 #1、#11）

- [ ] 待办视图 → 展开「重要日倒计时」→ 点任意一条 → **打开的是编辑框，不是新建框**
- [ ] 编辑框里名称、日期、每年重复都已填好
- [ ] 编辑框左下角有「删除」，点了有二次确认，确认后该条消失
- [ ] 建一条**每年重复**的重要日，日期设为**今年已经过去的日子**（比如今年 5 月 20 日）
- [ ] 该条显示的是 `D-xxx`（到明年的天数），**不是「已过 xxx 天」**
- [ ] 该条在列表里**不是灰色**

## 二、提醒（反馈 #2、#3）

- [ ] 新建日程 → 滚到表单最下方 → 看到「提醒」下拉
- [ ] 下拉里有：不提醒 / 准时 / 提前 5、10、15、30 分钟 / 提前 1 小时 / 提前 2 小时 / **提前 1 天（可定时刻）**
- [ ] 选「提前 1 天」→ 右侧出现一个时刻输入框
- [ ] 设成「提前 1 天 + 09:00」，建一条明天的日程 → 明天 09:00 应收到提醒（可等一天，或先信任自动化）
- [ ] 待办视图 → 右下「＋」→ 勾上「安排时间」→ **出现「待办提醒」下拉**
- [ ] 不勾「安排时间」时，**看不到**提醒下拉

## 三、重复规则（反馈 #6）

- [ ] 新建一条**周三**的课，选「每周」
- [ ] 星期多选里**「三」已经自动选中**，不用手点
- [ ] 选「每月」时，几号**自动等于这条日程的日期**

## 四、表单顺序与备注（反馈 #7、#8）

- [ ] 新建日程的表单从上到下是：标题 → 分类 → 时间 → 加入待办 → **备注** → 重复 → **提醒**
- [ ] 能填备注，保存后重新打开这条日程，**备注还在**

## 五、分类批量删除（反馈 #13）

- [ ] 设置 → 分类管理，每条分类右侧有「清空日程」按钮
- [ ] 点它 → 弹确认框「清空「XX」分类下的所有日程？」
- [ ] 确认后提示「已删除 N 条日程」
- [ ] 回到日历：**该分类的日程没了**，其它分类的日程还在
- [ ] 分类本身**还在**（没被删掉）

## 六、待办点开行为（反馈 #4）

- [ ] 建一条**纯任务**（不勾「安排时间」）→ 在待办里点它 → 打开的是**「编辑任务」**
- [ ] 建一条**带时间**的待办（勾「安排时间」）→ 点它 → 打开的是日程编辑（**已知**，下一版改样式）
