# AI待办软件 · 使用教程（试用版 v0.1.0）

> 一款装在 Windows 上的本地日程 + 待办软件。数据全部存在你自己电脑上，不注册账号、不上传云端。

---

## 一、安装

1. 双击 `AI待办软件-0.1.0-setup.exe`
2. 如果 Windows 弹出蓝色的「已保护你的电脑」提示：
   - 点**「更多信息」**
   - 再点**「仍要运行」**
   - 原因：这个试用版**没有买代码签名证书**，不是病毒。正式发布时会签名。
3. 选择安装位置（默认即可），一路下一步
4. 装完桌面会出现「AI待办软件」快捷方式

> 卸载方式：设置 → 应用 → 找到「AI待办软件」→ 卸载。**卸载不会删除你的数据**，数据仍在 `%APPDATA%\AI待办软件`。

├──────┬──────┬──────┬──────┬──────┬────┬─────┤

## 三、建一条日程

点右下角蓝色 **＋**。

| 填什么 | 说明 |
| --- | --- |
| **标题** | 必填。太长会自动省略号 |
| **分类** | 课程（蓝）/ 课外活动（橙）/ 个人生活（绿），决定色块颜色 |
| **时间** | 见下方四种形态 |
| **提醒** | 不提醒 / 准时 / 提前 5 / 10 / 30 分钟 |
| **加入待办** | 勾上后这条日程会出现在「待办」列表里 |
| **重复** | 见下方「重复规则」 |

### 四种时间形态

- **全天**：只填开始日期和结束日期，没有时刻。跨天就填两个不同日期，会出现在顶部全天行，连着的每一天都有
- **时间段**：最常用。可以「精确时间」也可以「按节次」
- **只有开始**：只知道几点开始 → 日历上是一条实线
- **只有结束**：只知道几点截止（比如「23:59 交作业」）→ 日历上是一条虚线

### 按节次填时间（懒人必备）

选「时间段」→ 切到 **「按节次」** → 选日期，再选「第 1 节 – 第 2 节」，右侧会实时显示 `08:00–09:35`。

**为什么好用**：课程表是按节次排的，不用每次查几点上课。第 1–2 节默认就是 08:00–09:35。

作息时间表本身可以在**设置 → 作息时间表**里改（见第七节）。

### 重复规则

- **不重复**（默认）
- **每天** / **每两周** / **工作日**（周一–周五）
- **每周**：会展开星期一~日，可以多选，比如只看「二、四」
- **每月**：填几号（1–31）
- 都能设**结束日期**，留空表示一直重复

底部会实时显示摘要，例如 `每周 二、四，直到 2027-01-15`。

## 四、查看与修改

### 切换粒度

工具栏最左边的 **日 / 周 / 月**：

- **日**：只看一天，时间轴放大
- **周**：七列（默认）
- **月**：6×7 网格，每格最多 2 条，多了显示「还有 N 条」

点月视图里的任意一天（**包括上下月的灰色日期**）会直接跳到那天的日视图。

`‹` `›` 按当前粒度前后翻，**今天**一键回到本周。

### 改和删

**点日程色块**（或横线、全天胶囊）→ 弹出编辑框，内容都已填好。

- 改完点**保存**立即生效
- 左下角**删除**有二次确认

**如果这条日程是重复的**，编辑框里会多一行「改动范围」：

| 选项 | 效果 |
| --- | --- |
| **仅这一次**（默认） | 只有点开的这一天变，其它天不动 |
| **整个序列** | 所有重复的实例一起变 |

删同理：选「仅这一次」时确认框会写「只删除这一次」。

## 五、待办视图

点顶部 **「待办」**，窗口会自动变窄（约 400×822）。

```
┌──────────────────────┐
│ 全部 | 课程 | 课外 | 个人 │  ← 分类筛选
├──────────────────────┤
│ ○  高等数学           │
│    14:00–15:30       │
│ ○  交实验报告         │
│    截止 23:59        │
│ ○  买牛奶             │
│    两盒               │
│                      │
│ 已完成 1 ▸           │  ← 折叠区
├──────────────────────┤
│ [回到日历]           │
└──────────────────────┘
                    ＋
```

- **勾选框**：点一下 → 淡出，移进「已完成」
- **点「已完成 N」**：展开回看，还能取消勾选
- **点行的其它位置**：打开编辑（日程开会打日程，任务开任务）
- **排序**：按时间先后，**没有时间的纯任务永远排最后**

### 新建待办

右下 **＋**：

- **不勾「安排时间」** → 纯任务，只有标题 / 分类 / 备注
- **勾上「安排时间」** → 出现日期 + 起止时刻，保存后会变成一条**带时间、自动加入待办**的日程，同时出现在日历里

### 重要日倒计时

列表下方有「重要日倒计时 · N 条 · 最近一条 D-3」：

- **默认折叠**，只占一行
- 右侧的 **＋** 不用展开就能直接新建
- 点标题行展开，看全部
- 未来显示 `D-n`，今天显示 `今天`，过去显示 `已过 n 天`

## 六、提醒与托盘

### 到点提醒

设了提醒的日程，到点会**同时**：

1. 弹 **Windows 系统通知**
2. 屏幕**右下角**出现一个迷你小窗（380×110）

迷你小窗：

- **不抢焦点**，你正在别处打字也不会被打断
- 点正文 → 唤起主窗口
- 点右侧 **×** → 关掉

> **即使主窗口已经收进托盘，迷你小窗照样会弹。**

### 关闭 ≠ 退出

点主窗口的 **✕**：窗口消失，但应用**还在后台跑**（托盘里），提醒依然生效。

托盘图标在屏幕右下角，：

- **左键单击** → 唤回主窗口
- **右键** → 菜单：打开主窗口 / 新建日程 / 退出
- **退出**会先弹确认「退出后将收不到提醒」，避免误退

## 七、设置

点标题栏中间的 **⚙**，打开 700×600 的设置弹层，六组直接列出。

### 外观

三选一：**浅色 / 深色 / 跟随系统**。切换**立即生效**，不用重启。

深色不是简单反色：底色偏暖棕，长时间看不刺眼。

### 作息时间表

每行一节，可以改开始/结束时刻、**加一节**、**删除**（后面的节次会自动重新编号）。

改乱了点「恢复默认 12 节」。

> 作息表改动**不会**自动重算已建的日程时间（那需要更复杂的规则），只影响以后按节次新建的日程。

### 分类管理

- 改名：直接点名字改，失焦即保存
- 换色：点 12 个小色块
- 提醒开关：`提醒开 / 提醒关`。**关掉后这个分类下所有日程都不提醒**，哪怕日程自己设了提醒
- 删除：内置分类不能删（按钮是灰的）

### 数据

| 按钮 | 作用 |
| --- | --- |
| **导出备份** | 选一个目录，生成 `ai-todo-backup-日期-时间.db` |
| **导入恢复** | 选一个 `.db` 备份覆盖当前数据。**会先自动把当前数据存一份 `pre-restore-*`**，恢复完需要重启应用 |
| **打开数据文件夹** | 在资源管理器里打开数据所在目录 |

> 导出前会自动把内存里的数据刷到磁盘（WAL checkpoint），所以**不会丢最近几分钟的改动**。

### 系统

- **开机自启**：开关，重启电脑后应用自动起来
- 版本号
- 数据目录路径

## 八、数据在哪

```
%APPDATA%\AI待办软件\data\app.db
```

在地址栏粘 `%APPDATA%\AI待办软件\data` 就能打开。

**建议**：每周导出一次备份，放到网盘或 U 盘。这个软件不联网，数据只在这一个文件里。

## 九、常见问题

**Q：Windows 说这是未知发布者，能装吗？**
A：能。试用版没有代码签名证书，点「更多信息 → 仍要运行」。如果你不放心，可以自己从源码编译（源码在仓库里）。

**Q：关掉窗口后找不到了？**
A：它在托盘里。点屏幕右下角的小图标（可能需要点「^」展开隐藏图标）就能唤回。要真正退出：托盘右键 → 退出。

**Q：提醒没响？**
按顺序检查：
1. 日程上是否设了提醒（编辑日程看「提醒」一行）
2. 该日程的**分类提醒开关**是否开着（设置 → 分类管理）
3. Windows 是否开了「勿扰模式」/ 专注助手
4. 应用是否被完全退出（托盘图标还在吗）

**Q：改了作息时间，以前的课时间没变？**
A：符合预期。作息改动只影响以后按节次新建的日程。

**Q：能同步到手机吗？**
A：不能。这一版是纯本地，不做账号与云端。

**Q：卸载会删我的数据吗？**
A：不会。数据在 `%APPDATA%\AI待办软件`，卸载后仍在。想彻底清掉就手动删这个目录。

**Q：卸载后重装，数据还在吗？**
A：在。装完打开就能看到原来的日程。
